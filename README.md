## גלגל הדמויות
הדף מציג רק את הגלגל, כפתור הסיבוב והתוצאה (הכותרת וההוראה נמצאות במצגת). אפשר להשתמש באותו גלגל עם שמות אחרים, בלי לשנות את הקובץ, דרך הכתובת:
`.../character-wheel/?names=שם1,שם2,שם3`

## חידון עמק החולה
13 שאלות לכיתות ד–ו, רק על מה שכתוב במסכי השיעור. השאלות וסדר התשובות מתערבבים בכל משחק, ואחרי כל תשובה מוצג הסבר קצר. את השאלות אפשר לשנות בראש הסקריפט שבקובץ (התשובה הנכונה היא תמיד הראשונה ברשימה).
